# 科研小助手 Agent —— 产品需求参考（源自《科研小助手Agent-AI大模型.pdf》）

> 本文件是 skill 的需求底稿，供模型在设计/实现/自检时对照。测试 PDF 放在 `pdf/` 目录。

## 1. 产品功能

### 1.1 PDF 文件管理和解析
- 基本 CRUD：上传论文 PDF（支持批量）；解析提取文字；更高级解析识别文档结构、公式、表格、图表。
- **1.1.1 内容去重**：按内容去重（文件名不同、内容相同/基本相同）。测试样例：`1706.03762v1.pdf` 与
  `1706.03762v7.pdf`（论文《Attention Is All You Need》的 arXiv v1 与 v7）。发现重复时提示用户选择保留哪个版本，
  尽可能提示保留更新版本。
- **1.1.2 细粒度解析**：要求能处理扫描图片型 PDF（`1706.03762v1_img.pdf`）和超长书籍
  （`UnderstandingDeepLearning_02_09_26_C.pdf`，541 页）。解析粒度参考：
  标题、作者（顺序/联系方式/单位）、摘要、一级标题（Introduction/Background/Experiment…）、
  二级/三级标题、表格、图表（chart）、公式、参考文献、附录。

### 1.2 知识问答
- **单篇问答**（RAG 等）：给出参考原文让用户能发现幻觉。示例问题：
  1. 《Attention Is All You Need》第 6 作者是谁，在哪个公司/机构？
  2. Adam 优化器的 β1、β2 分别设为多少？
  3. 训练 Base 模型用了多少个 GPU？什么型号？
  4. Transformer(big) 在 English-to-German 上的 BLEU？当时 SOTA？提升多少？
  5. 列出论文引用的关于 "Layer Normalization" 的参考文献完整作者与年份。
- **多篇问答**：示例：BERT 架构与原始 Transformer Encoder 的承袭关系、丢弃了哪个部分；
  对比 GPT-1/2/3 参数量变化；GPT-2 相对 GPT-1 在 LayerNorm 位置的关键调整（pre-LN）；
  GPT-1→GPT-3 最大上下文 Token 长度递增。

### 1.3 阅读和翻译
- 基本阅读：考虑原文排版（双栏/单栏）、公式与表格排版。
- 智能引导与快速速览：一级/二级标题做成树状导航栏（如快速跳到 3.2.2 Multi-Head Attention）；
  正文引用 `[11]` 可点击跳到 References 对应条目，并能跳回原位置。
- 翻译（英→中）：部分翻译（摘要/选中段落/划词/悬停）；整篇翻译（关注质量与可读性——
  可输出 Markdown/HTML 重排或重新排版 PDF，注意中英长度差异；代码和公式保留英文）；
  中英对照阅读（拖动一侧另一侧联动滚动到对应位置）。

### 1.4 论文自动下载和推荐
- 基本下载：给定论文名自动搜索下载入库；根据参考文献自动下载（可按内容筛选重要性，去掉凑数引用）。
- 下载最新论文：定期刷新 arXiv（参考 https://info.arxiv.org/help/oa/index.html ，可用 sickle 等 Python 库），
  找到与库内论文相关的新论文（大量引用库内论文或主题高度相关）。
- 每日/每周推荐：给出推荐理由（基于内容，如"在 xxx 基础上提出新 xxx 方法，在 xxx 数据集提升明显"）；
  含 GitHub 代码的优先；加入用户反馈（点击/点赞/踩）；多用户可考虑协同过滤。

### 1.5 论文分析与生成
1. 局域图谱：一次上传同方向 20 篇 PDF，自动解析引用与被引关系并在前端展示。
2. 核心节点挖掘：用图论算法找出"基石论文"与"边缘衍生论文"。
3. 自动综述：基于上述结果生成领域简短综述。
4. 未来工作探索：基于各篇 Future Work 提出值得探索的方向，考虑时间与最新工作，不提已被尝试过的 idea。

### 1.6 写作助手
1. 论文框架生成：给定 idea 生成框架（Abstract/Introduction/Related Work/References），References 必须真实无幻觉。
2. 论文架构拓扑图：生成 TikZ / Graphviz(DOT) / Mermaid / Python Matplotlib 脚本。
3. 数据可视化：上传实验 CSV → 生成精美表格/折线图/柱状图/三维雷达图等，
   并自动生成学术规范的 Figure Caption（说明内容 + 提炼核心趋势结论）。
4. 翻译：中文论文摘要或全文译成英文。
