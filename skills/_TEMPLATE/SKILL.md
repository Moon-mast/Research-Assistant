# <技能名> —— 一段标题

写给模型的说明。要点：
1. 明确“什么时候用它”（触发信号），别让模型乱用；
2. 给出**具体可执行的步骤**，最好能一次跑通；
3. 常用技巧、质量要求、坑，直接写进来，别留白让模型猜；
4. 需要给更多背景时，把细节放进本目录 `references/*.md`，它们会随本说明一起载入。

## 素材库（若声明了 library）
用 `library_list_<名>`（列目录）/ `library_read_<名>`（读文件）浏览，路径相对素材库根。

## 验收/合规
把“做对了”的标准写明（如语义标签、单文件自包含、可离线、许可署名等）。

> 部署提示：改完直接与模型对话即可；新技能会在下次 CLI/GUI 会话自动出现，
> 也可手动输入 `/skills` 查看、`/skill <名>` 预载。
